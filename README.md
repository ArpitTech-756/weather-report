## 🌦️ Smart Weather — Real-Time Weather Experience

I built a modern, user-friendly weather website using **HTML, CSS, and JavaScript** that provides real-time weather information for any location. The website is designed with a clean and intuitive interface so users can quickly understand current weather conditions at a glance.

Using **live location support**, the website can detect the user's current location and display accurate weather information for that area. Users can also search for different places and explore their current weather conditions.

The website provides detailed weather insights such as **temperature, humidity, rainfall, wind speed, weather conditions, and other important atmospheric details**. Every section is designed to make weather information simple, clear, and easy to understand.

This project helped me improve my skills in **JavaScript, API integration, responsive UI design, real-time data handling, and frontend development**, while focusing on creating a practical website that can be useful in everyday life.
